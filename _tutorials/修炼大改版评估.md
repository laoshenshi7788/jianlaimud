# 修炼大改版评估：「等级=主技能均值÷2」

> 参考：Nightmare4 abilities.c ResetLevel / Dead Souls QuestLevels / LP-2.4.5 ×1.5 表
> 结论先行：**方向正确，但不宜本轮实施**——需要全量重调 expNeeded/REALMS/气府容量/敌人数值四处耦合，建议作为 v2 版本号（SAVE_VER 递增+迁移）单独立项。

## 现状（本次已修的部分）
- 经验来源已多元化：战斗（伤害即修炼+击杀+首杀）、任务、事件、探索见闻、经营；修炼仅占每日气府容量封顶的份额——「无限刷级」已死。
- REALMS 双轨（层数+破境）完整，破境五途（水到渠成/丹药/灌顶/感悟/顿悟）。
- 遗留：等级与武学无耦合——学再多功法也不影响等级；等级只来自经验。

## 大改版设计草案（若实施）
1. **等级 = 玩家已学武功的品级加权均值 ÷ 2**（向下取整，最低 1）：
   - 权重 = 功法品级（凡1/良2/珍3/绝4/仙5/造化6）×熟练境（0-5 加权）
   - 效果：练粗浅功夫永远停在低境界；想升境界必须拜师/抄录/顿悟更高品功法并练熟——「练什么成什么」
2. **熟练度即经验**：每次用功法（战斗/演武）涨该门熟练，熟练满自动晋升门内层数
3. **气府容量保留**：改为限制「每日熟练度增长」而非经验，防挂机不变
4. **破境不变**：境界门仍需五途之一，但额外要求「至少两门门派品级功法达到人兵合一」——把引导链自然接上拜师/藏书阁
5. **迁移**：SAVE_VER+1；旧档按「等级×2 = 市井拳脚补差」反推，保证不掉境界

## 工作量评估
- 核心：~150 行（等级重算+熟练迁移+破境门改）
- 联动重调：ENEMIES 数值表、气府容量曲线、quests 奖励、authored 内容里的等级门（约 20 处）
- 风险：全游戏平衡重校；建议在 bak4 基础上开实验分支先跑数据

## 决定
本轮不做。当前「经验多元+气府封顶+破境双轨」已满足防刷级诉求；大改版等玩家反馈等级曲线手感后再动。
