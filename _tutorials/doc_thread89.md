# LPC/MudCore/MUD开发问题集中贴

首先感谢雪风老师创作的系列教程和MudCore核心框架，对新手来说，最缺乏的就是系统、详细的教程，特别是在这个泥巴极为小众的年代。虽然小众，泥巴独特的魅力依然深深吸引着一批爱好者和怀旧玩家，更有对创作泥巴游戏跃跃欲试的人群。然而相关教程却极为匮乏，常常让我这样的初学者感到茫然。雪风老师贡献的系列教程和MudCore核心框架，无疑为我们在迷雾中开辟了一条清晰的道路。
